# 🚀 Gemini Canvas Downloader

Download code from Google Gemini's Canvas with automatic file type detection.

## ✨ Features

- **Smart file detection** - Automatically detects the correct file extension (HTML, React, Python, etc.)
- **Multiple extraction methods** - Works with virtualized editors and large files
- **Keyboard shortcut** - Press `Ctrl+Shift+D` to download instantly
- **30+ languages supported** - HTML, JSX, Python, Java, Go, Rust, C++, PHP, and more

## 📥 Installation

1. Install **[Tampermonkey](https://www.tampermonkey.net/)** browser extension
2. Create a new script in Tampermonkey
3. Copy and paste the script code
4. Save and visit [gemini.google.com](https://gemini.google.com/)

## 🎮 Usage

### Option 1: Menu Button
1. Open any Canvas in Gemini
2. Click the **⋮** (three dots) menu
3. Select **"Download code"**

### Option 2: Keyboard Shortcut
Press `Ctrl+Shift+D` (or `Cmd+Shift+D` on Mac)

### For Large Files
If you see a warning message:
1. Click in the code editor
2. Press `Ctrl+A` (select all)
3. Click download again

## 🗂️ Supported Languages

**Backend:** Python, Java, Go, Rust, C++, C, PHP, Ruby, Kotlin, Swift, C#

## 🔧 Troubleshooting

**Problem:** "Unable to extract code"  
**Solution:** Press `Ctrl+A` to select all code, then download again

**Problem:** Wrong file extension  
**Solution:** The file downloaded correctly, just rename it manually

**Problem:** Download button missing  
**Solution:** Refresh the page and ensure Tampermonkey is enabled

## 💡 Tips

- Use `Ctrl+Shift+D` for fastest downloads
- Files are automatically named based on the Canvas title
- Works with all code lengths
